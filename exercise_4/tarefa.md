# Tarefa - Sistema de Produtos

Crie uma classe `Produto` com:

* `nome`
* `preco`
* `estoque`

Crie 4 produtos usando a classe:

* Monitor
* Headset
* SSD
* Teclado

A classe deve possuir:

* Um método `valorEstoque()` que retorna `preco * estoque`.
* Um método `mostrarProduto()` que exibe no console:

  * Nome
  * Preço
  * Estoque
  * Valor total do estoque

O método `mostrarProduto()` deve utilizar o método `valorEstoque()` para calcular o valor total.

Depois, teste os métodos utilizando os objetos criados.
