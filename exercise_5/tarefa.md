# Exercício 5

Crie uma função que some dois números e mostre o resultado na página.

## Instruções

- Crie uma função chamada `sum`.
- A função deve receber dois parâmetros.
- Retorne a soma desses dois números.
- Armazene o resultado em uma variável.
- Mostre o resultado na tela usando o DOM.

## Exemplo

```js
function sum(a, b) {
  return a + b;
}

const resultado = sum(2, 2);
console.log(resultado);
```

## Objetivo

Praticar funções e apresentação de resultados na página.
