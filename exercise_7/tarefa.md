# Exercício 7 - Manipulação do DOM

## JavaScript - O que foi feito

1. Pegou o elemento titulo com `getElementById("titulo")`
2. Fez `console.log()` do titulo
3. Alterou o texto da descrição com `innerText`
4. Pegou todos os produtos com `querySelectorAll(".produto")`
5. Fez `console.log()` dos produtos
6. Adicionou evento de clique no botão com `addEventListener()`
7. Mostrou mensagem no console quando clicado
8. Alterou o titulo ao clicar no botão

10. Adicionou o item à lista com `appendChild()`
