# Exercício 8 - Formulário com Validação

## JavaScript - O que foi feito

1. Selecionou todos os elementos do formulário com `querySelector()`
2. Adicionou evento de clique no botão com `addEventListener()`
3. Usou `preventDefault()` para não recarregar a página
4. Pegou os valores dos inputs com `.value`
5. Usou `.trim()` para remover espaços em branco
6. Validou se os campos obrigatórios foram preenchidos
7. Verificou se o checkbox de termos foi marcado com `.checked`
8. Fez `console.log()` de todos os valores
9. Alterou a cor de fundo com `document.body.style.background`
10. Exibiu alertas com `alert()` se a validação falhou
