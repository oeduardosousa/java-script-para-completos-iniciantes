# Exercício 9 - Cadastro de Jogador

## JavaScript - O que foi feito

1. Selecionou todos os inputs e elementos do formulário com `querySelector()`
2. Adicionou evento `submit` ao formulário com `addEventListener()`
3. Usou `preventDefault()` para não recarregar a página
4. Pegou todos os valores com `.value` e `.trim()`
5. Validou se todos os campos obrigatórios foram preenchidos
6. Verificou se o checkbox foi marcado com `.checked`
7. Usou `textContent` para mostrar mensagens de erro
8. Usou `className` para adicionar classes CSS diferentes (erro/sucesso)
9. Criou HTML dinâmico com template strings usando `${}`
10. Usou `innerHTML` para inserir o HTML gerado no resultado
11. Usou ternário para definir status (Titular ou Reserva)
